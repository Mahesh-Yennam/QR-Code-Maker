# Instant QR Code Maker Pro — Gamility Tools

A modern, high-resolution, 100% client-side QR Code generator supporting custom links, Wi-Fi networks, contact vCards, emails, SMS, and plain text with crisp PNG & SVG vector export.

---

## 🔒 100% Client-Side Privacy Guarantee

Unlike many online QR generators that send your URLs, Wi-Fi network passwords, and address books to third-party tracking APIs or cloud endpoints, this utility runs **entirely in your local browser**. 

All matrix computations, Reed-Solomon error correction encoding, and graphic rendering execute locally in client memory. **Zero network calls, zero tracking, and zero telemetry.**

---

## ✨ Features

- **Multi-Format Data Modes**:
  - **URL / Website**: Validated web links.
  - **Plain Text**: Notes, serial tags, cryptographic keys, messages.
  - **Wi-Fi Network**: SSID, Password, Encryption (WPA/WPA2, WEP, Open), and Hidden Network flags (creates standard `WIFI:S:...` strings for instant camera scans).
  - **Contact Card (vCard)**: Name, Phone, Email, Company, Title, and Website for instant address book import.
  - **Email**: Pre-filled recipient, subject, and message body.
  - **SMS / Phone**: Phone dialer or pre-filled SMS text message.
- **Reed-Solomon Error Correction**:
  - Low (L: 7% recovery)
  - Medium (M: 15% recovery — recommended standard)
  - Quartile (Q: 25% recovery)
  - High (H: 30% recovery — optimal for damaged prints or logos)
- **Visual Styling & Customization**:
  - Foreground & Background color pickers.
  - Curated color presets (Classic Monochrome, Neon Cyan, Emerald Matrix, Deep Violet, Solar Gold).
  - Adjustable quiet zone / margin border width (0 to 4 modules).
- **Pro Export Formats**:
  - **Download High-Res PNG** (up to 2048x2048px for sharp print reproduction).
  - **Download Scalable Vector Graphic (SVG)** for professional vector graphics software (Illustrator, Figma, Inkscape).
  - **One-Click Copy Image** to clipboard.
- **Responsive Dark Design**: Tailored glassmorphism UI styled for desktop, tablet, and mobile displays.
